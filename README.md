# Power BI Sales Performance Dashboard

An interactive Power BI dashboard designed to analyze sales performance, profitability, orders, quantity, product categories, regions, and monthly sales trends.

## Dashboard Preview

![Sales Performance Dashboard](Sales%20Performance%20Dashboard.png)

## Key KPIs

- Total Sales: 1.00M
- Total Profit: 93.44K
- Total Quantity: 12K
- Total Orders: 2K

## Dashboard Analysis

The dashboard provides insights into:

- Sales performance by product
- Sales distribution by category
- Sales performance across regions
- Profit by sub-category
- Monthly sales trends
- Year-based filtering
- Region and category filtering

## Project Objective

The objective of this project is to transform sales data into an interactive business intelligence dashboard that helps users understand sales, profitability, product performance, regional performance, and sales trends.
